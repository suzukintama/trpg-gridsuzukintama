# サイバーパンクTRPG 効果音パック

銃声、被弾、爆発、近接、ハッキング、乗り物の効果音と、継ぎ目なしの環境音ループをまとめたパックです。

銃・爆発・被弾・環境音は、CC0（パブリックドメイン相当）の生の録音をそのまま使っています。手を加えたのは、切り出し・音量合わせ・フェードと、複数の録音を順に並べることだけです。

ハッキング、義体、テック武器、AV（飛行車）、電脳空間、端末の通知のような「未来の音」は、現代の音をそのまま当てはめず、生の録音を素材にして作っています（`_src/gen_v8.py`・`_src/gen_v9.py`、2026-11-14）。食器や金属を鳴らした音、曲げたのこぎりの唸り、本物の火花、サーボ、リレー、無線のスケルチ、変圧器のうなり、ブラウン管の消磁、ハードディスク、キーボード、電子機器の電磁ノイズ、制作された楽曲素材を、速度の変更・時間の引き伸ばし・別の録音の響きを移す・細かく刻む、といった加工で作り替えています。発振器のピー音やゲーム風の電子音は使っていません。

合成音が残るのは、電車_車内放送・ホログラム広告・08_ラジオの声（音声合成モデル Kokoro・Chatterbox）と、下層のバーの曲だけです。心拍モニターとフラットラインは、実物の心電図モニターの録音です。

既存ゲームの音は使っていません。

- 試聴ページ：`sfx/index.html`（GitHub Pages なら `…/sfx/` を開けばブラウザで全部聴けます）
- 形式：効果音は MP3（48kHz）。環境音ループは OGG と MP3 の両方

## VTT（このリポジトリの `index.html`）での使い方

- **効果音（01〜06、09〜11）**：GMが効果音の「＋ 追加」から登録します。鳴らすと部屋の全員に聞こえます。
  `警報_施設ロックダウン` は、SEの繰り返し再生と組み合わせると鳴り続ける警報になります。
- **環境音ループ（07）**：BGMとして登録します。BGMはループ再生なので、そのまま環境音として流れ続けます。`01_銃` と `06_機械・乗り物` にある OGG 付きのループ（拳銃_撃ち続けループ、ドローン_ホバリング）も、同じくBGMとして登録してください。
  Chrome、Edge、Firefox なら **OGG** を選んでください。継ぎ目なしでループします。
  MP3 は形式の仕様上、ループの継ぎ目にごく短い無音が入ることがあります（OGGが鳴らない環境向けの予備です）。

### 音量の基準（耳を守るための上限）

すべてのファイルを、放送やゲームの音量基準に合わせた上限で抑えています（2026-11-14、全261ファイル）。どの音も、これより大きくなることはありません。上限を超えていたファイルは下げただけで、小さい音を持ち上げることはしていません。

| 対象 | 基準 | 出典 |
|---|---|---|
| すべて | トゥルーピーク -1 dBTP 以下 | EBU R128、Sony のゲーム音量基準（ASWG-R001） |
| 効果音（01〜06、09〜11） | 短期ラウドネス（3秒平均）の最大 -18 LUFS 以下 | EBU R128 s1（短い番組・CM向けの上限） |
| 効果音（01〜06、09〜11） | 瞬間ラウドネス（0.4秒平均）の最大 -14 LUFS 以下 | このパック独自の上乗せ。銃声のような一瞬の音は3秒平均では低く出るため |
| 環境音ループ（07ほか）、ラジオ（08） | 平均ラウドネス -23 LUFS 以下 | EBU R128。家庭用ゲーム機向けの Sony 基準は -24 LUFS ±2 |

- 効果音が環境音より 5 dB ほど大きく聞こえるバランスです。ボイスチャットの邪魔をしない大きさを狙っています
- ライブハウス、下層のバー、職業別のループなど、もともと -24〜-27 LUFS に下げてあったものはそのままです
- それでも大きく感じる場合は、VTT の効果音・BGMの音量で下げてください
- ラウドネスは ITU-R BS.1770 の方法で測っています。`_src/check_loudness.py` で全ファイルを確かめられます

### 作り方の要点

- 銃声は物理現象ごとに層を分けて合成しています。マズルの衝撃波（N波）、急速にこもっていく燃焼ガス、本体の低音、機関部の金属共鳴、スライドや薬莢の作動音です。
- 残響は合成したインパルス応答で畳み込んでいます。屋外ならビル壁からの不規則な跳ね返りと長い残響、屋内なら密な初期反射です。残響の大きさは、直接音とのエネルギー比をピンクノイズで較正して決めています。
- 環境音は、ループの継ぎ目付近に目立つ出来事（雷、サイレン、銃声など）を置かず、パワーを保つクロスフェードで閉じています。
- 仕上げは、ラウドネスの正規化（ITU-R BS.1770）とルックアヘッド付きリミッターで、トゥルーピークを -1 dBTP 以下に抑えています。

## 録音素材も集めたい場合（入手先リスト）

この作業環境からは外部の素材サイトに接続できなかったため、ダウンロードはしていません。自分で集めるときの入手先です。
**規約は変わることがあるので、使う前に各サイトで最新の利用規約を確認してください。**
セッションを配信する（とくに収益化する）場合は、商用利用可かどうかとクレジット表記の要否を必ず確認してください。

| サイト | 主な規約（確認時の目安） | 向いているもの |
|---|---|---|
| Sonniss「GDC Game Audio Bundle」（sonniss.com） | ロイヤリティフリー、商用可、クレジット不要 | プロ制作の銃声、爆発、環境音。リアルさなら一番 |
| 効果音ラボ（soundeffect-lab.info） | 無料、商用可、クレジット不要（素材の再配布は禁止） | 銃、戦闘、SF・電子音。日本語で探しやすい |
| Freesound（freesound.org） | 音ごとにライセンスが違う。**CC0で絞り込む**のが安全 | 「gunshot」「cyberpunk ambience」「rain city night」などで検索 |
| Pixabay（pixabay.com/sound-effects） | Pixabay Content License、クレジット不要 | 環境音、SF効果音 |
| Kenney（kenney.nl） | CC0 | 「Sci-fi Sounds」「Impact Sounds」。ゲーム調の短い音 |
| Zapsplat（zapsplat.com） | 無料会員はクレジット表記が必要 | 銃器と近未来系の数が多い |
| OtoLogic（otologic.jp） | CC BY 4.0（クレジット表記が必要） | SF、電子音、システム音 |
| ポケットサウンド（pocket-se.info） | 無料、クレジット表記が必要 | 銃声、戦闘 |
| BBC Sound Effects（sound-effects.bbcrewind.co.uk） | RemArc ライセンス。個人・教育・研究目的に限る | 本物の銃声や都市の環境音の録音。**配信や商用には使えない** |

既存ゲーム（たとえば Cyberpunk 2077）から抜き出した音は著作物なので、使わないでください。
