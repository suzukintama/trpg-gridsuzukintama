# サイバーパンクTRPG 効果音パック

銃声、被弾、爆発、近接、ハッキング、乗り物の効果音と、継ぎ目なしの環境音ループをまとめたパックです。

試聴ページで【実録】と付いている音は、CC0（パブリックドメイン相当）の実録音をもとに加工したものです。
それ以外の音は、`_src/` のPythonコードで一から合成しました。既存ゲームの音は使っていません。

- 試聴ページ：`sfx/index.html`（GitHub Pages なら `…/sfx/` を開けばブラウザで全部聴けます）
- 形式：効果音は MP3（48kHz）。環境音ループは OGG と MP3 の両方

ファイル名は16文字以内にしてあるので、VTTに読み込んでも名前が途中で切れません。

## VTT（このリポジトリの `index.html`）での使い方

- **効果音（01〜06）**：GMが効果音の「＋ 追加」から登録します。鳴らすと部屋の全員に聞こえます。
  `警報_施設ロックダウン` は、SEの繰り返し再生と組み合わせると鳴り続ける警報になります。
- **環境音ループ（07）**：BGMとして登録します。BGMはループ再生なので、そのまま環境音として流れ続けます。
  Chrome、Edge、Firefox なら **OGG** を選んでください。継ぎ目なしでループします。
  MP3 は形式の仕様上、ループの継ぎ目にごく短い無音が入ることがあります（OGGが鳴らない環境向けの予備です）。

### 音量の目安

- 銃声と爆発：ピークいっぱいまで出しています。いちばん大きい音です
- 被弾、近接、ハッキング：-15〜-18 LUFS 前後
- 環境音ループ：-19〜-22 LUFS。ボイスチャットの下に敷く想定なので、BGM音量の初期値（0.6）のままで使えます

## 音を作り直す・追加する

```bash
pip install numpy scipy soundfile pyloudnorm matplotlib
# ffmpeg も必要
cd sfx/_src
python3 gen_guns.py            # 01_銃 をすべて生成
python3 gen_guns.py sniper     # 1つだけ（キーは各ファイル末尾の JOBS を参照）
python3 gen_hits.py            # 02_被弾・着弾 / 03_爆発
python3 gen_misc.py            # 04_近接 / 05_ハッキング / 06_機械・乗り物
python3 gen_amb.py             # 07_環境音ループ（数分かかります）
python3 gen_rec.py             # 実録音ベースの音（上の合成版の一部を置き換えます。最後に実行）
python3 build_index.py         # 試聴ページを作り直す
SFX_QA=/tmp/qa python3 gen_guns.py   # 波形とスペクトログラムのPNGも出力する
```

乱数シードは固定なので、何度実行しても同じ音ができます。シードや引数（`cal` で口径、`bright` で明るさ、残響の種類など）を変えると別パターンを作れます。

### 作り方の要点

- 銃声は物理現象ごとに層を分けて合成しています。マズルの衝撃波（N波）、急速にこもっていく燃焼ガス、本体の低音、機関部の金属共鳴、スライドや薬莢の作動音です。
- 残響は合成したインパルス応答で畳み込んでいます。屋外ならビル壁からの不規則な跳ね返りと長い残響、屋内なら密な初期反射です。残響の大きさは、直接音とのエネルギー比をピンクノイズで較正して決めています。
- 環境音は、ループの継ぎ目付近に目立つ出来事（雷、サイレン、銃声など）を置かず、パワーを保つクロスフェードで閉じています。
- 仕上げは、ラウドネスの正規化（ITU-R BS.1770）とルックアヘッド付きリミッターで、トゥルーピークを -1 dBTP 以下に抑えています。

## 使っている実録音（すべて CC0）

`_src/rec/` に元の録音とクレジットがあります。CC0 なのでクレジット表記は必須ではありませんが、記録として残しています。

| フォルダ | 出どころ | ライセンス |
|---|---|---|
| `rec/guns/` | The Free Firearm Sound Library（Still North Media、OpenGameArt）の録音。GitHub の mrellcrane/smokeem と PanderMusubi/sound-effects-library-weapons を経由して入手 | CC0 1.0 |
| `rec/kenney/` | Kenney「Impact Sounds」「RPG Audio」（kenney.nl）。GitHub の sigco3111/assets-audio を経由して入手 | CC0 1.0 |
| `rec/amb/` | Freesound の録音12本。GitHub の CyberOoHim/ambient-sound を経由して入手（1本ごとの作者は `rec/amb/CREDITS.md`） | 各ファイル CC0 1.0 |

## 録音素材も集めたい場合（入手先リスト）

この作業環境からは外部の素材サイトに接続できなかったため、ダウンロードはしていません。自分で集めるときの入手先です。
**規約は変わることがあるので、使う前に各サイトで最新の利用規約を確認してください。**
セッションを配信する（とくに収益化する）場合は、商用利用可かどうかとクレジット表記の要否を必ず確認してください。

| サイト | 主な規約（確認時の目安） | 向いているもの |
|---|---|---|
| Sonniss「GDC Game Audio Bundle」（sonniss.com） | ロイヤリティフリー、商用可、クレジット不要 | プロ制作の銃声、爆発、環境音。リアルさなら一番 |
| 効果音ラボ（soundeffect-lab.info） | 無料、商用可、クレジット不要（素材の再配布は禁止） | 銃、戦闘、SF・電子音。日本語で探しやすい |
| Freesound（freesound.org） | 音ごとにライセンスが違う。**CC0で絞り込む**のが安全 | 「gunshot」「cyberpunk ambience」「rain city night」などで検索 |
| Pixabay（pixabay.com/sound-effects） | Pixabay Content License、クレジット不要 | 環境音、SF効果音 |
| Kenney（kenney.nl） | CC0 | 「Sci-fi Sounds」「Impact Sounds」。ゲーム調の短い音 |
| Zapsplat（zapsplat.com） | 無料会員はクレジット表記が必要 | 銃器と近未来系の数が多い |

| ポケットサウンド（pocket-se.info） | 無料、クレジット表記が必要 | 銃声、戦闘 |
