# サイバーパンクTRPG 効果音パック

銃声、被弾、爆発、近接、ハッキング、乗り物の効果音と、継ぎ目なしの環境音ループをまとめたパックです。

ほとんどの音は、CC0（パブリックドメイン相当）の生の録音をそのまま使っています。手を加えたのは、切り出し・音量合わせ・フェードと、複数の録音を順に並べることだけです。
合成音が混じるのは、閃光弾の耳鳴り、クラブ・電脳空間・下層のバーの音楽部分、電車_車内放送の英語の声（音声合成モデル Kokoro、Apache-2.0）と、下に書いた電子音です（試聴ページの説明に書いてあります）。既存ゲームの音は使っていません。
ハッキング（05）、端末・通知（10）と、職業別（11）の電子機器の音は、2026-11-03 に近未来寄りの合成音（`_src/gen_future.py`）で作り直しました。以前のモデムやブラウン管の録音から作った版は古く聞こえたためです。澄んだ電子音、低音のうねり、ノイズの掃引、細かいデータの粒を組み合わせていて、8ビットのゲーム音のようなピコピコした音にはしていません。銃（01）は 2026-11-01 に、ハンドガン・ライフル・アサルトライフル・機関銃・ミニガン・重火器の 6 系統に整理しました。

- 試聴ページ：`sfx/index.html`（GitHub Pages なら `…/sfx/` を開けばブラウザで全部聴けます）
- 形式：効果音は MP3（48kHz）。環境音ループは OGG と MP3 の両方

## VTT（このリポジトリの `index.html`）での使い方

- **効果音（01〜06、09〜11）**：GMが効果音の「＋ 追加」から登録します。鳴らすと部屋の全員に聞こえます。
  `警報_施設ロックダウン` は、SEの繰り返し再生と組み合わせると鳴り続ける警報になります。
- **環境音ループ（07）**：BGMとして登録します。BGMはループ再生なので、そのまま環境音として流れ続けます。`01_銃` と `06_機械・乗り物` にある OGG 付きのループ（拳銃_撃ち続けループ、ドローン_ホバリング）も、同じくBGMとして登録してください。
  Chrome、Edge、Firefox なら **OGG** を選んでください。継ぎ目なしでループします。
  MP3 は形式の仕様上、ループの継ぎ目にごく短い無音が入ることがあります（OGGが鳴らない環境向けの予備です）。

### 音量の目安

全ファイルの音量は 2026-11-01 にそろえてあります（`_src/level_pack.py`）。突然ひとつだけ大きな音が鳴って、PL の耳が痛くなることはありません。

- 効果音（01〜06、09〜11）：いちばん大きい瞬間の音量（400ミリ秒の瞬間ラウドネス）を -16〜-12 LUFS の幅に収めています。爆発も薬莢の落下も、差は最大 4 dB です
- 環境音ループ（07）：平均 -22 LUFS。ボイスチャットの下に敷く想定なので、BGM音量の初期値（0.6）のままで使えます。ライブハウスのループは -24 LUFS で、少し控えめにしてあります。下層のバー、終演後、客入り2_まばら、出待ちは -25、客入り1_ほぼ空と演奏前の静けさは -27 です。職業別のループ（工房、診療所、オフィス、警察無線、荒野の風、焚き火、記者会見）は -24、生体モニターは -27 です
- 溶接、カメラのシャッター、手錠、ケースの留め金は一瞬で終わる音なので、ピークは他と同じでも、瞬間ラウドネスの値は -22〜-20 LUFS と低めに出ます
- ラジオ（08）：平均 -20 LUFS
- どのファイルもピークは 0 dBFS 未満です

## 音を作り直す・追加する

```bash
pip install numpy scipy soundfile pyloudnorm matplotlib
# ffmpeg も必要
cd sfx/_src
python3 gen_guns.py            # 01_銃 をすべて生成
python3 gen_guns.py sniper     # 1つだけ（キーは各ファイル末尾の JOBS を参照）
python3 gen_hits.py            # 02_被弾・着弾 / 03_爆発
python3 gen_misc.py            # 04_近接 / 05_ハッキング / 06_機械・乗り物
python3 gen_amb.py             # 07_環境音ループ（数分かかります）
python3 gen_rec.py             # v2（実録音ベース）
python3 gen_v3.py              # v3（生の録音をそのまま。最後に実行すると現在の内容になります）
python3 gen_train.py           # 電車_車内放送（Kokoro のモデルが必要。取得方法はファイル冒頭に記載）
python3 gen_v4.py              # v4（拳銃4種、金属音の作り直し、ドローン・重機関砲などの追加。v3 のあとに実行）
python3 gen_v5.py              # v5（rec/inbox の新しい録音から。v3・v4 のあとに実行すると現在の内容になります）
python3 gen_v6.py              # v6（rec/inbox の録音から切り出した音。通過音、環境音ループなど。inbox の各録音との対応は rec/inbox/日本語一覧.md）
python3 gen_v7.py              # v7（銃の6系統＋重火器、実機の録音によるハッキング音、跳弾2本の作り直し。v6 のあとに実行）
python3 gen_bar.py             # 下層のバー（07。ざわめき・物音は rec/bar の録音、曲はここで合成）
python3 gen_live.py            # ライブハウスのループ（07）と 09_観客の反応（すべて rec/live の録音から）
python3 gen_radio.py           # 08_ラジオ（Kokoro のモデルが必要。RADIO_VOICE で声を変えられる）
python3 pack_v7.py             # v7 で引退した音（銃種別の細かい銃声、重複した通過音、ゲーム用の電子音、56kモデム）を削除する。gen_future.py より前に実行
python3 gen_future.py          # 近未来の電子音（すべて合成）：05_ハッキングの電子音、10_端末・通知、11_職業別の小物、生体モニターのループ。gen_v7 と pack_v7 のあとに実行
python3 gen_roles.py           # 11_職業別の実録音と、職業別のループ（07。すべて rec/roles の録音から）
python3 level_pack.py --apply  # 最後に必ず実行。全ファイルの音量をそろえる（引数なしなら測るだけ）
python3 build_index.py         # 試聴ページを作り直す
SFX_QA=/tmp/qa python3 gen_guns.py   # 波形とスペクトログラムのPNGも出力する
```

乱数シードは固定なので、何度実行しても同じ音ができます。シードや引数（`cal` で口径、`bright` で明るさ、残響の種類など）を変えると別パターンを作れます。

### 作り方の要点

- 銃声は物理現象ごとに層を分けて合成しています。マズルの衝撃波（N波）、急速にこもっていく燃焼ガス、本体の低音、機関部の金属共鳴、スライドや薬莢の作動音です。
- 残響は合成したインパルス応答で畳み込んでいます。屋外ならビル壁からの不規則な跳ね返りと長い残響、屋内なら密な初期反射です。残響の大きさは、直接音とのエネルギー比をピンクノイズで較正して決めています。
- 環境音は、ループの継ぎ目付近に目立つ出来事（雷、サイレン、銃声など）を置かず、パワーを保つクロスフェードで閉じています。
- 仕上げは、ラウドネスの正規化（ITU-R BS.1770）とルックアヘッド付きリミッターで、トゥルーピークを -1 dBTP 以下に抑えています。
